# ProHammer Battle Companion

A standalone ProHammer 40K mission and scoring companion.

## GitHub Pages

1. Create a GitHub repository and copy these files into the repository root.
2. Commit and push to `main`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/(root)`, then save.
6. GitHub will publish the site at `https://YOUR-USERNAME.github.io/REPOSITORY/`.

The app is a static HTML/CSS/JavaScript site and needs no server-side code.

## Install as an app

The included web app manifest and service worker allow supported browsers to offer installation as a standalone app when served over HTTPS, such as GitHub Pages.
